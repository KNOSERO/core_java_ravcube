# Ravcube Core Java

Ravcube Core Java provides reusable Spring integration libraries and shared test
infrastructure. It standardizes common technical capabilities across services:
cache, idempotency, persistence helpers, search, events, client streams,
security, discovery, fault tolerance, and container-based testing.
